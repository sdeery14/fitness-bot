# Fitness Plan Generation & Scheduling Flow

## Overview
This document explains how fitness plans are generated by AI and then converted into scheduled events.

## Data Flow

```
User Requirements
      ↓
Conversation Agent (gathers info, asks questions)
      ↓
FitnessPlanInput (structured requirements with phase dates)
      ↓
build_fitness_plan() function tool
      ↓
Phase-specific agents (workout_phase_agent, meal_phase_agent)
      ↓
FitnessPlanOutput (complete plan with all details)
      ↓
Database (fitness_plans.plan_snapshot)
      ↓
ScheduleService.create_schedule()
      ↓
Schedule Entries (daily workout/meal/grocery/prep events)
```

## Key Components

### 1. FitnessPlanInput Schema
The conversation agent builds this structure to call `build_fitness_plan()`:

```python
FitnessPlanInput(
    primary_goal="Build muscle and strength",
    fitness_level="intermediate",
    workout_frequency=4,
    equipment_access="Full gym",
    time_per_session=60,
    dietary_restrictions=[],
    meal_frequency=4,
    injuries_or_conditions=[],
    
    # PHASES DEFINE ALL DATES - No separate start_date/end_date
    phases=[
        PhaseInput(
            name="Foundation Phase",
            start_date="2025-12-13",  # Plan starts here
            end_date="2026-01-09"
        ),
        PhaseInput(
            name="Building Phase", 
            start_date="2026-01-10",  # Must be contiguous
            end_date="2026-02-06"     # Plan ends here
        )
    ],
    
    workout_plan_description="...",  # High-level strategy
    meal_plan_description="...",     # High-level nutrition
    workout_metadata=WorkoutPlanMetadata(...),
    meal_metadata=MealPlanMetadata(...),
    schedule_preferences=SchedulePreferences(...)
)
```

**Important Design Decisions:**
- ✅ Phases define ALL dates - first phase start = plan start, last phase end = plan end
- ✅ No "today" option - AI must choose explicit dates
- ✅ No duration_weeks field - calculated from phase dates
- ✅ Phases must be contiguous (no gaps or overlaps)

### 2. Phase Date Validation

```python
# For each phase:
- Parse start_date and end_date (YYYY-MM-DD format only)
- Validate end_date > start_date
- Calculate duration_weeks (must be 2-16 weeks per phase)
- Check phase continuity (gap between phases ≤ 1 day)

# For entire plan:
- start_date = first_phase.start_date
- end_date = last_phase.end_date
- duration_weeks = total calculated from dates (must be 4-52 weeks)
```

### 3. Phase Generation

For each phase, the function:

1. **Calls workout_phase_agent** with context:
   - Phase number, name, duration, dates
   - Phase objectives (derived from phase name)
   - Overall workout strategy
   - User constraints (fitness level, frequency, equipment, time)
   
2. **Calls meal_phase_agent** with context:
   - Same phase context
   - **phase_start_day** (e.g., "Saturday") for grocery/meal prep scheduling
   - Overall nutrition strategy
   - User constraints (dietary restrictions, meal frequency)

3. **Creates PhaseOutput** combining both:
   ```python
   PhaseOutput(
       phase_number=1,
       name="Foundation Phase",
       objectives=["Build foundational movement patterns", ...],
       start_date="2025-12-13",
       end_date="2026-01-09", 
       duration_weeks=4,
       workout_details=<from workout_phase_agent>,
       meal_details=<from meal_phase_agent>
   )
   ```

**Key Insight:** AI provides **day names** (Sunday, Wednesday), NOT offsets. The schedule service calculates offsets programmatically.

### 5. Schedule Creation

After plan is saved to database, `ScheduleService.create_schedule()` is called:

```python
# In schedule_service.py

def _calculate_day_offset(start_date: date, target_day_name: str) -> int:
    """Calculate offset from start_date to target day of week.
    
    Example:
        start_date = 2025-12-13 (Saturday)
        target_day_name = "Sunday"
        Result: 1 (Saturday + 1 day = Sunday)
        
        target_day_name = "Wednesday"  
        Result: 4 (Sat → Sun → Mon → Tue → Wed)
    """
    start_day_idx = start_date.weekday()  # 0=Mon, 6=Sun
    target_day_idx = day_map[target_day_name.lower()]
    
    if target_day_idx >= start_day_idx:
        return target_day_idx - start_day_idx
    else:
        return (7 - start_day_idx) + target_day_idx
```

For each grocery/meal prep schedule entry:
```python
# From plan_snapshot
entry = {
    "target_day_name": "Wednesday",
    "time": "7:00 PM",
    "repeats_every": 7
}

# Calculate first occurrence
phase_start = date(2025, 12, 13)  # Saturday
day_offset = _calculate_day_offset(phase_start, "Wednesday")  # = 4
first_date = phase_start + timedelta(days=4)  # = Dec 17 (Wednesday)

# Create recurring schedule entries
current_date = first_date
while current_date <= plan_end_date:
    ScheduleEntry(
        entry_type="meal_prep",
        entry_date=current_date,  # Dec 17, 24, 31, etc.
        entry_time=time(19, 0),
        ...
    )
    current_date += timedelta(days=7)  # repeats_every
```

## Why This Design?

### ✅ Benefits
1. **Simple for AI** - Just name days ("Sunday"), no math
2. **Reliable** - Programmatic date calculation eliminates errors
3. **Flexible** - Any phase length, any frequency pattern
4. **Explicit** - All dates specified upfront, no "today" ambiguity
5. **Validatable** - Can check phase continuity and duration limits

### ❌ Problems Solved
1. ~~AI calculating wrong day_offset~~ → Now AI just names days
2. ~~"today" causing inconsistent plan dates~~ → Now requires explicit dates
3. ~~Splitting duration evenly across phases~~ → Now each phase has explicit dates
4. ~~Wednesday prep appearing on Thursday~~ → Now programmatic calculation is correct

## Example End-to-End

User: "I want a 12-week plan starting next Saturday"

Agent builds:
```python
FitnessPlanInput(
    primary_goal="...",
    phases=[
        PhaseInput(
            name="Foundation Phase",
            start_date="2025-12-13",  # Next Saturday (agent calculates)
            end_date="2026-01-09"     # 4 weeks later
        ),
        PhaseInput(
            name="Building Phase",
            start_date="2026-01-10",  # Next day
            end_date="2026-02-06"     # 4 weeks later
        ),
        PhaseInput(
            name="Peak Phase",
            start_date="2026-02-07",
            end_date="2026-03-06"     # 4 weeks later (total=12)
        )
    ],
    ...
)
```

meal_phase_agent generates:
```python
grocery_shopping_schedule=[
    {"target_day_name": "Saturday", "time": "9:00 AM", "repeats_every": 7}
],
meal_prep_schedule=[
    {"target_day_name": "Sunday", "time": "2:00 PM", "repeats_every": 7}
]
```

Schedule service creates:
- Grocery shopping: Dec 13, 20, 27, Jan 3, 10, ... (every Saturday)
- Meal prep: Dec 14, 21, 28, Jan 4, 11, ... (every Sunday)

✅ Perfect alignment with calendar!
