# Evaluation Reports

This directory contains detailed evaluation reports for fitness-bot agents.

## Purpose

Reports document:
- Performance metrics and ratings
- Test coverage and scenarios
- Issues discovered and fixed
- Recommendations for improvements
- Progress over time

## When to Create Reports

Create a new report when:
- ✅ Significant agent improvements are made
- ✅ Evaluation datasets are expanded
- ✅ Major bugs are fixed
- ✅ Performance baselines are established
- ✅ Before/after comparisons are valuable

## Report Naming Convention

```
{agent_name}_{YYYY-MM-DD}.md
```

Examples:
- `query_agent_2025-12-18.md`
- `fitness_coach_agent_2025-12-20.md`
- `intake_agent_2025-12-15.md`

## Report Structure

Each report should include:

1. **Executive Summary**
   - Key metrics
   - Overall performance
   - Major findings

2. **What Was Fixed/Changed**
   - Problems addressed
   - Solutions implemented
   - Impact of changes

3. **Test Coverage**
   - Test scenarios
   - Query types / interaction patterns
   - Edge cases

4. **Performance Analysis**
   - Rating breakdown
   - Execution times
   - Quality patterns

5. **Known Limitations**
   - Remaining issues
   - Edge cases not covered
   - Performance bottlenecks

6. **Recommendations**
   - Immediate actions
   - Future enhancements
   - Next steps

7. **Comparison to Previous**
   - How metrics improved
   - What changed
   - Progress indicators

## Using Reports

Reports help with:
- **Decision making:** Prioritize which agents need work
- **Onboarding:** Understand agent capabilities and limitations
- **Retrospectives:** Review what worked and what didn't
- **Planning:** Identify next improvements
- **Stakeholder updates:** Share progress and findings
